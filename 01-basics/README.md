# ABAP Fundamentals

Personal SAP ABAP learning and practice repository.

This repository contains examples covering fundamental ABAP programming concepts, including data types, internal tables, structures, field symbols, and Open SQL.

## Topics

* ABAP variables and data types
* Conditions and loops
* Internal tables
* Structures
* Field symbols
* Open SQL
